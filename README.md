# Java-ArrayList-NameSearch

A Java program that reads lists of boys' and girls' names from text files, searches for specific names, and identifies names that appear in both lists.

## Features

- Reads names from text files into `ArrayList` collections
- Searches for names using a custom search method
- Checks whether a name appears in both lists
- Identifies and prints names shared by both lists
- Displays the number of names in each list

## How to Run

This project was developed in Eclipse.
1. Import the project into Eclipse.
2. Ensure `BoyNames.txt` and `GirlNames.txt` are in the expected project directory.
3. Run the `BoysAndGirlslNames` class.
